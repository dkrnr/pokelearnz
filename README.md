# PokeLearn 🎮
Voice-powered educational companion for kids using VALSEA AI

## Problem
Kids across South Asia struggle to engage with learning tools 
that don't understand their accents or languages.

## Solution  
Talk to your favourite Pokemon in your natural accent — 
VALSEA understands Sri Lankan and Tamil accented English, 
Sinhala, and Tamil. OpenAI responds in character.

## Tech Stack
- VALSEA API (voice transcription + sentiment)
- OpenAI gpt-4o-mini
- PokéAPI (all 1025 Pokemon)
- Plain HTML/CSS/JS
- Netlify
