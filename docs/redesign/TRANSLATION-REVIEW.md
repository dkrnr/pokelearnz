# Human language review required

Every Sinhala and Tamil string below is machine-translated, unreviewed and withheld from the child lesson UI. Selecting a draft language keeps English lesson text and English local read-aloud; the grown-ups area explains this. The selected language is used only for optional voice transcription. A native speaker must review meaning, reading level, pronunciation and cultural suitability before enabling lesson translations.
