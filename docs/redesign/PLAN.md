# PokeLearn: play, wonder, stop

Audience: children aged 6–9, with limited reading, and their grown-ups.

## Principles
- Warm, rounded, colorful toy-box visuals. Large illustrated choices, 56px minimum controls, icon plus word on every button.
- Short instructions, optional local read-aloud, optional sounds off by default. No remote voices or automatic audio.
- A buddy with visible idle, listening, thinking, celebrating and goodbye states; reduced-motion alternatives. One replaceable buddy module owns all character names and sprite paths.
- Finite authored lessons, gentle retries, one celebration, and a calm stopping screen with a real-world idea. No reward counters, streaks, pressure or chat loops.
- Preserve offline/PWA, optional consent-based device storage, parent information, EN/SI/TA scaffolding and test infrastructure. Keep unreviewed translations out of authoritative lesson UI.
- No changes to backend functions, hosting settings, main, history or deployment.

## Screens
1. Play shelf: six illustrated activities across science, maths and words.
2. Activity bench: picture-led steps, local listening, undo/reset and visible exit.
3. Completion: one celebration, discovery recap and Done for now.
4. Goodbye: buddy waves and a real-world suggestion.
5. Ask: one bounded question/answer, recording opt-in, honest failures, retry and mock-answer development mode.
6. Grown-ups: actual data recipients, consent/withdrawal, language review notice, install/update help, fan disclaimer and buddy choice.

## Activities
Each is designed for approximately 3–5 minutes of child-paced exploration, prediction, checking and an optional real-world observation; no timers.
- Science: Plant helpers — build with light, water and air; examine roots/leaves.
- Science: Animal homes — tap-to-sort familiar animals into land/water habitats.
- Maths: Build a number — build quantities with counters and compare groups.
- Maths: Shape match — match everyday outlines to circle, triangle and square.
- Words: First sounds — match pictures to initial letters (English phonics).
- Words: Story builder — order illustrated beginning, middle and end scenes.
