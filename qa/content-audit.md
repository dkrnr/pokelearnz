# Content/media and utility scope audit

The source revision is in source-manifest.json. This audit covers the Discovery Camp connected proof, not an expanded catalog of subject mini-games.

| State/surface | C | V | Pairing |
|---|---:|---:|---|
| Arrival learning choice | 1 | 1 | One choice instruction paired with the local companion and seedling in the same learning workspace. Three prompt controls are choices, not three independently headed explanatory sections. |
| Plant experiment | 1 | 1 | Explanation paired with the live specimen. On desktop it occupies the adjoining scene; on touch layouts the same SVG specimen is inside the workbench beside its input controls. |
| Optional check/retry | 1 | 1 | One prediction/check instruction paired with the same seedling state. Mobile/tablet maintain it in the notebook. |
| Factual recap | 1 | 1 | One learning recap paired with the resolved plant, retained as the same DOM specimen. |
| Finish | 1 | 1 | Rest/recap with companion and completed specimen when the activity was completed. Early stopping still has a meaningful companion rest state. |

The section selector `.activity-content` counts each substantive learning instruction and its primary choices. The companion toolbar and notebook footer are task navigation utilities; the question composer is a bare form; header/footer are navigation; buddy picker is a utility chooser; install/grown-up dialogs are utility instructions/settings/disclosures. These utility scopes are explicit, not marketing sections. All their rendered text, forms and controls still undergo the text/geometry/contrast/unlabeled-control audit. The primary activity never exceeds three controls; optional pause/finish routes remain adjacent as task navigation.

Initially visible identity/companion assets are documented as eager exceptions. The hero uses a native lazy default and is promoted to eager only if its position belongs in the initial viewport for the actual layout/state. Picker images mount only in an open dialog and are disposed on closing. Temporarily inactive background media is detached into reserved placeholders during a modal and restored on exit; it is not required to compete with the active dialog for rendering. SVG scenery/experiment diagrams contain no baked-in instructional text.

The six bundled starter artworks and Pikachu shiny variant were pinned and decoded in local QA. Dynamic search keeps every existing name reachable; it does not prefetch or certify all 1,025 remote image variants. Those have a named-image fallback and need live connectivity. Shiny variants beyond bundled Pikachu similarly need connectivity. No claim of a full animated rig or facial poses.

Languages: complete authored local lesson and UI translated to Sinhala, English AI reply behavior explicitly retained. Tamil is voice input with English interface. Sinhala editorial quality requires native review. Browser gates measure en/si; Tamil input selection is in functional evidence.
