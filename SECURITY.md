# Security reporting

This university portfolio prototype has not been approved for a public service for children. Provider policy, language safety, real devices and deployed safeguards still need review.

Use this repository's **Security → Report a vulnerability** when available. Otherwise open an issue requesting a private reporting channel; omit exploit details until a private channel is agreed. Do not include credentials, audio, transcripts, personal information or real child questions in public issues or pull requests.

Reports should identify the affected branch/commit, the impact and synthetic reproduction steps. There is no guaranteed response time or bug bounty. Security fixes go through a review branch and regression checks; contributors must not deploy or merge to main automatically.
